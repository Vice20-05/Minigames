MINI GAMES - F1 Racing and Battle Tanks
=======================================

You need Java 21 or newer. Don't have it? Get it free from https://adoptium.net
(pick "Temurin 21" or newer and install it like any program).
Keep the files in this folder together.

WINDOWS
    Double-click  run.bat   (or double-click Minigames.jar)
    If Windows shows "Windows protected your PC": More info -> Run anyway.

MACOS
    Double-click  run.command   (it opens a Terminal window, leave it open while playing)
    The first time, macOS blocks it because it isn't from the App Store:
      - click Done
      - open System Settings -> Privacy & Security, scroll down, click "Open Anyway"

LINUX
    Double-click  run.sh   (or in a terminal:  ./run.sh)
    If it doesn't start: right-click run.sh -> Properties -> allow running it as a program.

MUSIC
    The volume slider and the Mute button are on the main menu.
    They count for the menu and both games, and are remembered.

SCORES
    Online, scores go to the global leaderboard by themselves.
    Without internet they are saved on this computer, in the ".minigames" folder
    in your home folder (with your music setting).

Music: all songs are CC0 (public domain), from OpenGameArt.org.
